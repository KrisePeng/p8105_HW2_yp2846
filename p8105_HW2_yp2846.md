The cleaned subway entrance dataset contains 1868 rows(observations) and
19 columns(variables).

The variables include subway line and station name, station latitude and
longitude, routes served, whether entry is allowed, whether vending is
available, entrance type, and ADA compliance.

I cleaned the variable names using janitor::clean_names(), retained only
the variables relevant to the analysis and converted the entry variable
from “YES” and “NO” character values to a logical variable with TRUE and
FALSE.

The resulting dataset is not completely tidy because the routes served
are stored across multiple columns, from route1 through route11 rather
than in a single route variable.
